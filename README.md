<h1>Ходилка-бродилка</h1>
Простая 2D игра на pygame. Ходи по лабиринту, собирай цветочки (C) и найди выход (E). Управление WASD для движения, ESC для выхода.

Как играть и запускать
Установи pygame командой pip install pygame. Скачай все файлы в одну папку и запускай game.py. Карта лежит в map.txt — там S это пустое место и старт, 1 это стены, C это цветочки, E это выход.
